# Qualification OpenVisio v23.8

Auteur : Abdelhalim Talbi.

Contrôle différentiel géométrique des routes SAN : vérification périodique (une mise à jour locale sur seize), repli global sur divergence. Tests unitaires dédiés et suite cumulative.

Limites : exécution des tests sous Linux, sans capture native Windows. Les snapshots présents sont historiques, et les performances Windows ne sont pas mesurées.
