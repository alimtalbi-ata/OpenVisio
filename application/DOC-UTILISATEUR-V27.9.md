# OpenVisio v27.9 — Cockpit recommandations SAN

Auteur : Abdelhalim Talbi

Depuis la page principale, cliquer sur « Cockpit recommandations SAN ». Charger un JSON de corrections ou utiliser la démonstration. Cliquer sur « Analyser la sélection ». Consulter les métriques, les priorités et les conflits, filtrer les lignes puis exporter en CSV/JSON.

Le cockpit utilise les données déclarées uniquement ; aucune modification des connexions, du zoning ou des équipements SAN. Les gains sont des estimations. Les captures Windows réelles ne sont pas disponibles pour cette livraison.
