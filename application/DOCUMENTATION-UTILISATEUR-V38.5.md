# OpenVisio v38.5 — Guide utilisateur

Auteur : Abdelhalim Talbi.

## Démarrer rapidement

Cliquez sur **Démarrer…** dans la barre supérieure : **Nouveau diagramme**, **Ouvrir un fichier**, ou **Choisir un modèle**. La création d’un nouveau document conserve la confirmation existante si le diagramme contient des formes.

**Enregistrer** exporte le document JSON ; **Exporter SVG** crée une image vectorielle. Les outils SAN avancés restent dans **Outils avancés**.

## Limites

L’interface graphique et les exécutables Windows n’ont pas été qualifiés sur Windows dans cette livraison.
