# OpenVisio v28.2 — Windows
Auteur : Abdelhalim Talbi

## Nouveautés
- Correction de trois régressions de version (titre, bannière, liste de versions de recette).
- Projection en lecture seule des connexions SAN concernées lorsque le SVG comporte `data-connection-id` et que le diagramme JSON déclare des liens correspondants.
- Couleurs des connexions : Fabric A bleu, Fabric B violet, fabric inconnue ambre.
- Les connexions sans correspondance SVG ne sont pas créées artificiellement.

## Utilisation
Ouvrir `san-canvas.html` dans le navigateur Windows, importer le diagramme JSON et les corrections JSON puis lancer la projection. L'outil n'agit pas sur les switches ni les baies.

## Limites
Aucune capture réelle Windows v28.2 n'a été effectuée. Les snapshots précédents ne prouvent pas la qualification graphique de cette version.
