# OpenVisio v28.8 — Inspecteur de chemins SAN
Auteur : Abdelhalim Talbi

Ouvrir index.html dans un navigateur Windows compatible avec les modules ES. Sélectionner un serveur, un switch, une baie ou une connexion dans le canvas. Le panneau « Inspection SAN » présente les chemins FC documentés et les équipements cliquables. Les liens Fabric A sont indiqués en bleu, Fabric B en violet et les données ambiguës en ambre. La vue est plafonnée à 30 chemins affichés et le calcul à 300 chemins pour limiter les coûts.

L'analyse est documentaire, en lecture seule ; elle ne démontre ni le multipathing actif ni la conformité réelle du zoning. Aucune capture réelle Windows n'a été effectuée.
