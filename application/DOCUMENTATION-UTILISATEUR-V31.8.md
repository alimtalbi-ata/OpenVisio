# OpenVisio v31.8 — Matrice des écarts zoning SAN

Auteur : Abdelhalim Talbi.

Dans Import SAN, charger un export Brocade/Cisco, puis utiliser « Analyser les écarts » dans la matrice Fabric/VSAN/switch/zone. Filtrer P2/P3/P4, exporter CSV. Les attributs Fabric et switch non présents sont affichés « Non documenté » ; aucune appartenance n’est inventée. Les différences entre membres actifs et configurés sont des écarts documentaires P2, les preuves insuffisantes P3. Aucun changement du diagramme ni des équipements.
