# OpenVisio v38.2 — sauvegarder et rouvrir un diagramme SAN
Auteur : Abdelhalim Talbi

1. Éditer les domaines de défaillance des équipements et des connexions dans l’inspecteur.
2. Utiliser **Exporter JSON** pour enregistrer le diagramme. Un domaine invalide entraîne un refus et un message explicatif.
3. Utiliser **Ouvrir JSON** pour relire le fichier. Les domaines sont vérifiés avant le remplacement du diagramme actif.
4. Ouvrir le diagnostic SAN et lancer l’analyse sur le diagramme courant.

**Qualification** : ces instructions décrivent le parcours prévu par le code, non une recette graphique Windows exécutée.
