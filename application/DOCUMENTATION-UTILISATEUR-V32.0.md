# OpenVisio v32.0 — Guide utilisateur
Auteur : Abdelhalim Talbi

1. Ouvrir un diagramme contenant les objets SAN et les WWPN des connexions.
2. Importer un extrait de configuration SAN depuis le panneau Import SAN.
3. Dans la matrice des écarts de zoning, cliquer sur **Connexions FC** lorsqu’une correspondance WWPN exacte est trouvée.
4. Le canvas souligne les connexions et équipements documentés. Le bouton est désactivé si aucune connexion n’est identifiée.
5. La provenance Fabric, VSAN, zone et lignes source reste affichée.

**Prudence :** une correspondance WWPN est une corrélation documentaire, pas une preuve que la connexion appartient à la zone active, ni une panne constatée. L'import demeure non destructif.
