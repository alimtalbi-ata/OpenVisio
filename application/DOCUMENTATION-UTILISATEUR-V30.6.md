# OpenVisio v30.6 — Guide utilisateur

Auteur : Abdelhalim Talbi

Dans la matrice de résilience SAN, lancer l’analyse du document actif, puis choisir « Panne A : chemins » ou « Panne B : chemins » sur la ligne serveur/baie. Les connexions identifiées sont surlignées : rouge = chemin perdu, vert = survivant, orange = dépendance partagée, gris pointillé = chemin ambigu. La simulation ne valide ni zoning, ni masking, ni multipathing réel. Les résultats peuvent être tronqués selon les limites de parcours. La sélection est effacée au changement de document.
