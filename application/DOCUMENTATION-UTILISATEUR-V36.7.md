# OpenVisio v36.7 — cache portable Windows

Auteur : Abdelhalim Talbi.

Exécuter `Build-OpenVisio-Windows.cmd` sur Windows x64 pour construire les distributions. La version portable extrait les ressources intégrées dans `%LOCALAPPDATA%\OpenVisio\assets\36.7`. Les extractions utilisent des répertoires temporaires distincts; le cache déjà complet est réutilisé. La compilation et les tests d’installation natifs Windows restent à effectuer.
