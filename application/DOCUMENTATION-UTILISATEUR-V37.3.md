# OpenVisio v37.3 — Guide utilisateur

Auteur : Abdelhalim Talbi.

Ouvrir un diagramme contenant nodes/edges, puis le panneau Diagnostic de redondance SAN A/B. Cliquer « Analyser le diagramme ouvert », puis « Chemin A » ou « Chemin B » pour afficher la route documentée avec équipements intermédiaires et liens. Un bouton désactivé signifie qu’aucune route n’a été trouvée. « Localiser » cible seulement les extrémités. L’analyse ne modifie pas le document.

Sous Windows, lancer `Build-OpenVisio-Windows.cmd` pour tenter de produire l’installateur et le portable. Les binaires ne sont pas inclus dans le ZIP source.
