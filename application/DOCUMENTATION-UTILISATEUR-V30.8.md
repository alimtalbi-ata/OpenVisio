# OpenVisio v30.8 — Guide utilisateur

Auteur : Abdelhalim Talbi.

Dans le panneau « Résilience SAN », analyser le document actif, puis cliquer « Détail FC » sur une ligne serveur/baie. Déplier chaque chemin pour voir les liens, ports, WWPN, Fabric, ISL et anomalies documentaires. Utiliser « Exporter traces CSV » pour conserver le détail.

Les métadonnées absentes sont signalées ; aucune découverte réelle de matériel, zoning, masking ou MPIO n’est réalisée. Les données proviennent exclusivement du diagramme.
