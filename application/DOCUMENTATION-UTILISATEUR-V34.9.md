# OpenVisio v34.9 — Guide utilisateur

Auteur : Abdelhalim Talbi.

## Comparateur SAN

Utiliser les catégories Tout, Comparer, Connectivité, Applications, puis le champ de recherche. Les deux filtres sont combinés. Entrée ouvre la première analyse visible ; Échap efface la recherche. Les calculs et données restent inchangés.

## Installation Windows

Exécuter `Build-OpenVisio-Windows.cmd` depuis un poste Windows avec accès Internet pour générer l’installateur. Le script prépare les outils et WebView2. La compilation et la recette native n’ont pas été effectuées dans cet environnement Linux.
