# OpenVisio v35.0 — Guide utilisateur Windows

Auteur : Abdelhalim Talbi.

## Synthèse SAN

Ouvrir le comparateur de topologies SAN. La **Vue synthétique SAN** affiche huit résumés d’analyse avec un accès direct à chaque résultat. Cliquer sur **Actualiser les résultats** après le chargement de nouveaux diagrammes. **Voir l’analyse** amène à la section correspondante, sans changer les données ni relancer les calculs.

## Construction Windows

Sous Windows, exécuter `Build-OpenVisio-Windows.cmd` depuis la racine des sources. Ce script tente de préparer les dépendances et de générer l'installateur. Connexion Internet et droits appropriés nécessaires. La compilation et l'installation natives n'ont pas été vérifiées dans cet environnement.

## Limitations

Le comparateur HTML historique demeure volumineux : la vue synthétique améliore la navigation mais ne remplace pas le moteur ni les sections existantes. Les indicateurs sont documentaires, pas des relevés réels des équipements SAN.
