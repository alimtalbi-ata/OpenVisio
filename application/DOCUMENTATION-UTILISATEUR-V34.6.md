# OpenVisio v34.6 — Guide utilisateur
Auteur : Abdelhalim Talbi

## Comparaison de topologies SAN
Ouvrir **Comparer topologies**. Une barre de navigation persistante propose Comparaison, Zoning, Relations, Chemins, Ports, Applications, Matrice, Chaînes, Accès et Synthèse. Sélectionner une rubrique fait défiler vers son résultat sans recalculer ni masquer les autres sections. Les exports et calculs antérieurs restent accessibles.

## Construction Windows
Lancer `Build-OpenVisio-Windows.cmd` sous Windows avec accès Internet. Le script prépare les outils et tente de produire `dist\installer\OpenVisio-Setup-v34.6-x64.exe`. La compilation et l'installation réelle ne sont pas vérifiées dans cette livraison.

## Qualification
Les tests Node vérifient le contrat d'intégration et le code applicatif ; ils ne valident ni WinForms ni l'installateur.
