# OpenVisio v30.0 — Résilience SAN
Auteur : Abdelhalim Talbi

Dans le canvas principal, ouvrir « Résilience SAN · v30.0 », cliquer « Analyser le document actif », filtrer P1–P4 et exporter CSV. Les boutons d’identifiants demandent la sélection d’un objet. Les modifications invalident les résultats.

Les priorités sont indicatives ; aucun diagnostic matériel ou multipathing réel n’est certifié. Aucune modification du diagramme ou du SAN n’est effectuée.
