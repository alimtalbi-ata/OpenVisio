# OpenVisio v29.8 — Dépendances communes Fabric A/B

Auteur : Abdelhalim Talbi.

Dans le canvas principal, ouvrir « Dépendances communes Fabric A/B » puis cliquer « Analyser les dépendances ». Le document actif est utilisé en lecture seule. Les terminaux serveur et baie sont exclus de la détection des transits communs. Le bouton Localiser demande la sélection du composant dans le canvas. Les résultats sont déclaratifs ; ils ne prouvent pas le multipathing réel. Si l’exploration est tronquée, les résultats sont incomplets.
