# OpenVisio v38.3 — Utilisation
Auteur : Abdelhalim Talbi.

Ouvrir le diagramme, sélectionner les équipements et connexions, renseigner les propriétés de résilience SAN dans l'inspecteur, puis utiliser Exporter JSON. Pour réouvrir, utiliser Ouvrir JSON. Lancer le diagnostic SAN pour analyser les chemins A/B, leurs alternatives et les domaines de défaillance documentés.

Sur Windows x64, lancer `Build-OpenVisio-Windows.cmd` pour construire les distributions. La présence d'un exécutable ou la réussite de sa compilation n'a pas été vérifiée dans cet environnement.
