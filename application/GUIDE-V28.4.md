# OpenVisio v28.4 — panneau SAN intégré

Ouvrir index.html via OpenVisio-Windows.bat. Sélectionner une forme ou un lien dans le canevas principal : le panneau affiche les connexions déclarées, leur Fabric A/B et les équipements adjacents. Les boutons « Voir » changent la sélection. Aucun accès réseau ou modification des données. Les liens sans Fabric explicite sont classés « inconnue ».
