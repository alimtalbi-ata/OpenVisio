# OpenVisio v31.9 — Navigation contextuelle des écarts de zoning
Auteur : Abdelhalim Talbi

1. Importer un export SAN textuel dans le panneau d’import.
2. Ouvrir Corrélation SAN → Matrice des écarts → Analyser les écarts.
3. Cliquer « Localiser » sur une ligne dont le switch correspond exactement à un objet unique du diagramme.
4. Survoler le bouton pour lire Fabric, VSAN, zone et lignes de provenance.

La navigation est désactivée lorsque le switch est absent ou ambigu. Aucune correspondance de zone/connexion n'est inventée. Les données importées sont documentaires et peuvent être partielles.
