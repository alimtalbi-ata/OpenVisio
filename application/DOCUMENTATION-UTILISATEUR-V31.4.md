# OpenVisio v31.4 — Alias SAN et provenance des zones

Auteur : Abdelhalim Talbi.

Le rapprochement des chemins peut résoudre les alias WWPN explicitement fournis dans les données importées. Les cycles d’alias sont ignorés. L’état du zoning est `unknown` tant qu’une preuve explicite `active` ou `configured` n’est pas disponible. Une absence dans un export partiel n’est pas une preuve de panne.

Les contrôles ne sont pas connectés aux équipements et ne modifient pas le diagramme.
