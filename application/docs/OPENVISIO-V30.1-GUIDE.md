# OpenVisio v30.1 — Résilience SAN

Auteur : Abdelhalim Talbi.

## Utilisation
1. Démarrer OpenVisio sous Windows avec le lanceur fourni.
2. Ouvrir un diagramme SAN, puis le panneau « Résilience SAN ».
3. Lancer « Analyser le document actif » et filtrer les priorités P1 à P4.
4. Naviguer vers les composants ou exporter les résultats CSV.

Les diagnostics reposent sur le diagramme, ne prouvent pas le multipathing réel et ne modifient aucun équipement.

## Qualification visuelle
Aucune nouvelle capture réelle Windows réalisée dans cet environnement. Ne pas présenter les aperçus comme des captures réelles.
