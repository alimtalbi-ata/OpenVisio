# OpenVisio v28.5 — Inspecteur SAN

Auteur : Abdelhalim Talbi.

Dans le canvas, sélectionner un équipement ou un lien, puis utiliser le filtre Toutes / Fabric A / Fabric B / Non renseignée. Les lignes communes restent visibles. Filtre purement visuel, aucune modification du modèle. La présence de WWPN et ports dépend des attributs renseignés dans le diagramme.

La sélection de corrections et le multipathing physique ne sont pas validés par cette vue.
