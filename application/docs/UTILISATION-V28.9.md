# OpenVisio v28.9 — Simulation SAN
Auteur : Abdelhalim Talbi

Dans le canvas principal, sélectionner un objet puis consulter « Chemins SAN de bout en bout ». Choisir « Perte Fabric A », « Perte Fabric B » ou un switch documenté pour calculer les paires serveur/baie impactées. Aucune modification des diagrammes ou équipements n’est effectuée. Les résultats sont purement déclaratifs, non une preuve de multipathing.
