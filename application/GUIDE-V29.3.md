# OpenVisio v29.3 — Simulation SAN sur document actif
Auteur : Abdelhalim Talbi

Dans l’éditeur, ouvrir « Simulation SAN ». La case « Utiliser le document actif » charge les nœuds et liens de la session sans réimport. Sélectionner Fabric A/B ou un équipement puis cliquer Simuler. Le rendu colore les connexions documentées. Une modification du document invalide le résultat précédent ; relancer la simulation. Il reste possible de charger un JSON explicitement.

**Sécurité :** simulation purement documentaire, aucune commande sur les équipements. La qualification graphique Windows et les captures réelles ne sont pas effectuées dans cet environnement.
