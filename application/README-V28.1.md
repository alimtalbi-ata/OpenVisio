# OpenVisio v28.1 — Canvas SAN

Auteur : Abdelhalim Talbi.

Ouvrir `san-canvas.html` depuis le serveur local (`npm run serve`) et charger un diagramme JSON contenant `objects` et `connections`, puis une liste de corrections JSON avec `affectedObjectIds`. Les surbrillances sont une projection documentaire, pas un état SAN mesuré. Les connexions sont identifiées dans le rapport, sans modification des chemins réels. Cette page est accessible depuis l’éditeur principal.

Captures Windows : non réalisées dans cet environnement ; aucune capture historique ne vaut recette v28.1.
