# OpenVisio v28.3 — Navigation SAN
Auteur : Abdelhalim Talbi

Ouvrir `san-canvas.html` via le serveur local (`npm run serve`), charger les JSON du diagramme et des corrections, puis cliquer **Analyser et projeter**. Sélectionner un équipement dans la liste ou cliquer sur un nœud SVG pour voir les corrections et les chemins déclarés. Cliquer sur une correction pour afficher les identifiants des objets concernés. Les données ne sont jamais écrites dans les fichiers d'origine.

Limites : aucune découverte FC réelle ; pas de validation graphique Windows ; les snapshots historiques ne constituent pas une capture v28.3.
