# OpenVisio v30.9 — Guide utilisateur Windows
Auteur : Abdelhalim Talbi

1. Lancer `OpenVisio-Windows.bat` sur Windows.
2. Ouvrir le diagramme SAN dans l’éditeur principal.
3. Dans **Résilience SAN**, cliquer **Analyser le document actif**, puis **Détail FC**.
4. Lire les anomalies P1/P2/P3 de cohérence documentaire et exporter **Anomalies FC** en CSV.

Contrôles : format WWPN, ports manquants, continuité des nœuds et WWPN, Fabric inconnue, traversée A/B et ports ISL. Les alertes ne prouvent pas une panne réelle. Les WWPN manquants restent signalés par la trace existante.

La classification P1/P2/P3 est indicative et non une priorité d'incident ITIL.
