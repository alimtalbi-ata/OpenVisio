# OpenVisio v29.1 — Guide utilisateur

Auteur : Abdelhalim Talbi.

Depuis index.html, ouvrir « Simulation SAN avant/après v29.1 ». Charger un diagramme JSON avec `nodes[]` et `edges[]`, choisir une panne Fabric A/B ou un équipement, cliquer Simuler. Les liens rouges sont perdus, les verts conservés. Exporter le CSV si besoin. Aucun équipement réel n’est interrogé.

**Limites :** rendu SVG simplifié dans une page liée au canvas principal ; aucune capture Windows réelle ni validation du multipathing. La visualisation nécessite des identifiants de liens et nœuds cohérents.
