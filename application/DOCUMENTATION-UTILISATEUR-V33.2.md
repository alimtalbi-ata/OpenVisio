# OpenVisio v33.2 — Guide utilisateur
Auteur : Abdelhalim Talbi

## Interface
Le bandeau « Espace de travail » propose Édition (diagramme prioritaire), Analyse SAN (diagnostics SPOF, résilience, simulation et import), et Outils avancés (tous les panneaux). La sélection est conservée localement. Ctrl+K ouvre le lanceur de commandes.

## Windows
Exécuter `Build-OpenVisio-Windows.cmd` depuis un poste Windows connecté à Internet pour tenter la compilation et la création du setup. La construction dépend du SDK .NET, d’Inno Setup et de WebView2. La disponibilité des téléchargements et de winget doit être vérifiée.

## Qualification
La suite de tests JavaScript ne remplace pas la validation de l’exécutable Windows. Voir `QUALIFICATION-V33.2.txt` et `SNAPSHOTS-V33.2.md`.
