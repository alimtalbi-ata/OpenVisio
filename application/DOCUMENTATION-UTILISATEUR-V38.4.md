# OpenVisio v38.4 — Guide utilisateur

Auteur : Abdelhalim Talbi.

## Démarrage rapide

1. **Nouveau** crée un diagramme vierge.
2. Ajoutez des formes avec le ruban ou la bibliothèque, puis reliez-les avec **Connecteur**.
3. **Enregistrer** télécharge le document JSON OpenVisio. **Ouvrir** recharge ce document.
4. **Exporter SVG** produit une représentation graphique.
5. **Outils avancés** contient Cockpit SAN, comparaison de topologies, câblage et fonctions de sauvegarde/restauration.

Les actions avancées ont été regroupées sans supprimer leurs identifiants, afin de conserver les interactions JavaScript existantes. Le fonctionnement graphique et la compilation Windows ne sont pas encore qualifiés nativement.
