# Documentation livree a chaque version

A partir de v39.0, inclure systematiquement documentation/ dans le ZIP cumulatif et executer `node scripts/verify-release-docs.mjs` avant diffusion. Actualiser le manuel de reference et l addendum pour chaque version, remplacer les captures uniquement par des captures reelles identifiees, et conserver un inventaire des ecrans non captures.
