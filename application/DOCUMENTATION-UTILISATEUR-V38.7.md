# OpenVisio v38.8 — Guide utilisateur

Auteur : Abdelhalim Talbi

## Inspecteur
Sélectionnez une forme ou un lien, puis choisissez Général, Apparence, Connexions, SAN ou Résilience. Toutes rétablit la vue globale. La recherche retrouve une propriété même si sa catégorie n’est pas sélectionnée. Le bouton Réinitialiser revient aux propriétés essentielles.

## Limites
Les catégories filtrent les propriétés existantes sans les modifier. Les captures natives Windows et la compilation Windows ne sont pas disponibles dans cet environnement.
