# OpenVisio v35.1 — Guide utilisateur
Auteur : Abdelhalim Talbi

## Synthèse SAN
Ouvrir la comparaison de topologies puis utiliser la vue synthétique SAN. Le champ « Filtrer les analyses et résultats » recherche à la fois le titre et le résumé des analyses. Échap efface le filtre. Le bouton « Actualiser les résultats » recharge les informations affichées. « Voir l’analyse » déplace le focus vers la section correspondante. Le filtrage ne modifie pas le diagramme ni les calculs.

## Windows
Lancer `Build-OpenVisio-Windows.cmd` sur Windows pour préparer les outils et générer l'installateur. Cette chaîne exige Internet au premier lancement et n'a pas été exécutée sur Windows dans cette livraison.

## Limites
Les analyses SAN restent documentaires et ne consultent pas les équipements réels. La vue synthétique ne remplace pas encore le dialogue historique.
