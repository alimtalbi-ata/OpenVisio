# OpenVisio v37.5 — Guide utilisateur

Auteur : Abdelhalim Talbi

Dans le diagnostic SAN, cliquez « Analyser le diagramme ouvert ». La colonne « Indépendance » indique Indépendants, Point commun ou Incomplet. « Points communs » surligne les éléments partagés. « Chemin A » et « Chemin B » affichent séparément les routes documentaires. Aucune modification du diagramme.
