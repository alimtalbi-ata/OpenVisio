# OpenVisio v30.2 — Résilience SAN
Auteur : Abdelhalim Talbi

Ouvrir le panneau Résilience SAN, lancer Analyser le document actif, filtrer P1–P4, puis cliquer Surbrillance. Les identifiants doivent être présents dans les attributs data-id/data-object-id/data-connection-id du canvas. Une nouvelle photographie du document invalide le rapport. Un simple rafraîchissement graphique conserve le résultat. Analyse documentaire uniquement.
