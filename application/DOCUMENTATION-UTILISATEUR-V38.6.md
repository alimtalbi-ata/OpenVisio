# OpenVisio v38.6 — Guide utilisateur
Auteur : Abdelhalim Talbi

## Inspecteur simplifié
Sélectionner un objet sur le diagramme. L’inspecteur affiche par défaut les champs essentiels.
- **Rechercher** : saisir un nom de propriété ; la recherche montre aussi les champs avancés masqués par le mode Essentiel.
- **Propriétés SAN** : affiche les attributs SAN (Fabric, site, châssis, alimentation, contrôleur, WWPN, LUN, zoning).
- **Réinitialiser** : efface la recherche et revient aux propriétés essentielles.
- **Tout afficher** : conserve l’accès aux propriétés complètes.

La sauvegarde et les analyses SAN existantes sont conservées. Les contrôles sont des filtres de présentation, sans modification du document.

## Windows
Exécuter `Build-OpenVisio-Windows.cmd` sur Windows x64 pour tenter la construction. Aucun EXE natif n’a été compilé dans cet environnement.
