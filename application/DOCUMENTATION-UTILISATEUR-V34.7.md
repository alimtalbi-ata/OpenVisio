# OpenVisio v34.7 — Guide utilisateur

Auteur : Abdelhalim Talbi.

## Comparaison SAN
Ouvrir le comparateur de topologies, puis saisir une section dans le champ « Rechercher une section SAN ». Les boutons de navigation sont filtrés sans recalculer ni modifier les données. Entrée ouvre la première section visible ; Échap efface le filtre.

## Construction Windows
Sur Windows, exécuter `Build-OpenVisio-Windows.cmd`. La construction native et la recette de l’installateur ne sont pas vérifiées dans cet environnement Linux.
