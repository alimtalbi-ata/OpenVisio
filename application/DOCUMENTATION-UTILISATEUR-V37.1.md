# OpenVisio v37.1 — Documentation utilisateur

Auteur : Abdelhalim Talbi.

## Diagnostic SAN du diagramme courant

Ouvrir un diagramme, puis ouvrir **Comparaison de topologies**. Dans **Diagnostic de redondance SAN A/B**, cliquer **Analyser le diagramme ouvert**. Les résultats sont en lecture seule, calculés à partir du document actif et ne représentent pas une mesure réelle des équipements. L’import JSON reste disponible.

## Windows

Sur Windows x64 : lancer `Build-OpenVisio-Windows.cmd`. Le script vise un EXE portable et un installateur. La compilation et l’exécution natives ne sont pas vérifiées dans cet environnement Linux.
