# OpenVisio v29.6 — SPOF dans le canvas
Auteur : Abdelhalim Talbi

Ouvrir le panneau Matrice SPOF dans l’éditeur, analyser le document actif, filtrer P1–P4 puis cliquer sur Localiser. Les éléments SVG exposant `data-object-id` ou `data-connection-id` reçoivent un surlignage temporaire. Le surlignage est retiré à l’invalidation du document. Les recommandations sont affichées dans la matrice. Les fabrics sans correspondance d’objet directe ne sont pas surlignées : une notification explicite est affichée.

Cette analyse est documentaire, sans découverte de matériel ni action SAN. Les classifications P1–P4 sont indicatives.
