# OpenVisio v31.7 — Guide utilisateur

Auteur : Abdelhalim Talbi.

Dans le panneau Import SAN, importer un export texte Brocade ou Cisco MDS, puis ouvrir Corrélation import SAN et choisir **Comparer actif et configuré**. Le tableau affiche les zones par VSAN, les membres présents seulement dans la configuration déclarée ou active et une recommandation. Export CSV possible.

**Attention :** les exports partiels, les alias non résolus et les états inconnus ne prouvent aucune panne. Les résultats sont documentaires et ne modifient pas le SAN.
