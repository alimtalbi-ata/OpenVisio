# OpenVisio v39.0 — Release documentaire fiabilisée

Auteur : Abdelhalim Talbi

## Évolutions
- Validation renforcée des documents Word et PDF : signatures, intégrité ZIP interne DOCX et version visible.
- Contrôle du manifeste SHA256 des livrables documentaires.
- Guide de vérification reproductible et procédure de publication cumulative.
- Maintien des fonctionnalités de l'éditeur v38.9 ; aucune compilation native Windows revendiquée.

## Limites de qualification
Les captures Windows réelles, l'installateur et l'exécutable portable ne sont pas générés dans cet environnement.
