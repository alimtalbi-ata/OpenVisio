# Qualification OpenVisio v25.0
Auteur : Abdelhalim Talbi

Audit géométrique intégré au panneau de câblage : lecture des tracés SVG, détection d'ancrages décrochés, segments non orthogonaux et collisions. Action de localisation, sans mutation implicite. Limites : 250 liens / 500 équipements, 80 anomalies affichées.

La recette Windows/Chromium n'a pas été exécutée ici ; aucune capture Windows v25.0 n'est présentée comme réelle. Les snapshots historiques sont conservés dans le ZIP.
