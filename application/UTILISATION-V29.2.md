# OpenVisio v29.2 — Simulation SAN dans le canvas
Auteur : Abdelhalim Talbi

Ouvrir index.html depuis le serveur local habituel. Déployer le panneau « Simulation SAN v29.2 », importer le diagramme JSON correspondant au dessin courant, choisir Fabric A/B ou un équipement et cliquer sur Simuler. Les connexions dont les identifiants concordent sont colorées en rouge (perdues) ou vert (conservées). Le bouton Effacer supprime la projection. Export CSV disponible.

**Limites** : import explicite du diagramme, absence de synchronisation automatique avec le document ouvert ; le rendu peut remplacer les éléments SVG et donc effacer les couleurs lors d'un rafraîchissement. Résultats documentaires, aucune commande envoyée aux SAN. Aucun snapshot réel Windows v29.2 disponible.
