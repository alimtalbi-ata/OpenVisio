# OpenVisio v28.0 — guide Windows
Auteur : Abdelhalim Talbi

Ouvrir le serveur local Windows fourni dans `windows/`, puis accéder à `san-recommendations.html` depuis l’éditeur. Charger un tableau JSON de corrections, cliquer sur Analyser et utiliser la vue Avant / Après simulation. Cliquer sur une correction dans la projection pour retrouver sa ligne dans le tableau.

**Limites** : représentation déclarative par groupes, pas une découverte topologique SAN ni une validation de chemins physiques. Gains estimatifs. Aucun changement des fichiers diagrammes ni des équipements. Les couleurs indiquent anomalie, proposition ou absence de changement, pas un état mesuré.
