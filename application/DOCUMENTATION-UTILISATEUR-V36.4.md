# OpenVisio v36.4 — Diagnostic SAN A/B

Auteur : Abdelhalim Talbi.

Dans le comparateur de topologies, utiliser « Diagnostic de redondance SAN A/B », sélectionner un fichier JSON contenant `nodes` et `edges`. Les chemins et anomalies sont affichés sans modification du fichier. Taille maximale : 10 Mo. Le diagnostic actuel nécessite un import manuel ; il ne lit pas encore automatiquement le diagramme courant.

Construction Windows : `Build-OpenVisio-Windows.cmd`. Qualification : `Qualify-OpenVisio-Windows-Functional.cmd`. La compilation et la recette native doivent être exécutées sur Windows.
