# OpenVisio V43.27 — ShapeSheet units, dimensions and conditional geometry

**Author: Abdelhalim Talbi**

## Supported subset

The bounded ShapeSheet scalar evaluator recognizes a conservative set of universal units immediately after a numeric literal. Lengths normalize to inches and angles to radians. Common `in`, `ft`, `cm`, `mm`, `m`, `km`, `mi`, `yd`, `pt`, `deg` and `rad` forms are supported, as are universal forms such as `5[deg,A]`, `2[ft,D]`, `3[in,P]` and implicit geometry units `DL`, `DP` and `DA`.

Basic comparisons (`=`, `==`, `<>`, `!=`, `<`, `<=`, `>` and `>=`) return numeric Boolean values. `IF(condition, when_true, when_false)` evaluates only the selected value branch. Comparisons reject explicit length/angle mismatches, and the selected result must match the dimension of its target geometry cell. For example, `IF(Width > 1.25 in, 10 mm, 5 mm)` can compute a length-valued target without treating an angle as a length.

The tokenizer, branch skipping, nesting depth, formula length, token count, finite-result and magnitude limits remain enforced. No `eval`, imports or execution of formula code are introduced.

## Safety and fidelity boundaries

- This is a deliberately bounded subset, not a complete ShapeSheet interpreter. Text formulas, general Boolean logic, arbitrary functions, full unit algebra and formula-bearing non-geometry dependencies remain unsupported. Chained comparisons are refused.
- Unsupported, cyclic, ambiguous, non-finite or dimensionally invalid geometry formulas retain cached values and emit fidelity warnings. Strict VSDX fidelity mode refuses unresolved formulas instead of silently treating cached geometry as fully evaluated.
- Integration coverage uses synthetic VSDX packages. Microsoft Visio Desktop round-trip fidelity is **NOT TESTED**. Windows CI/build evidence applies only to the exact commit identified in the generated manifest.

## Reference

Microsoft documents the ShapeSheet `IF` function and comparison syntax, including `IF(Height > 1.25 in, 5, 7)`, at [IF function (Visio ShapeSheet reference)](https://learn.microsoft.com/en-us/office/client-developer/visio/if-function). This implementation intentionally supports only the bounded numeric geometry subset described above.
