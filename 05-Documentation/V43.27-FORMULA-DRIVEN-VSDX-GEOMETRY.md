# OpenVisio V43.27 — formule de géométrie VSDX et fidélité stricte

Auteur : **Abdelhalim Talbi**

## Correctif

L'import externe de pages Visio lit les valeurs numériques mises en cache des cellules de géométrie. Si une cellule de position, de taille, de pivot ou d'angle contient aussi une formule Visio, ces nombres ne reproduisent pas nécessairement le résultat calculé par Microsoft Visio. Avant ce correctif, le cache pouvait être utilisé sans avertissement lorsque la forme n'était ni tournée ni groupée.

V43.27 compte les formes importées qui ont une formule dans l'une de ces cellules : `PinX`, `PinY`, `Width`, `Height`, `LocPinX`, `LocPinY` ou `Angle`. L'import géométrique standard demeure disponible mais inscrit un avertissement de fidélité et quelques exemples bornés dans les métadonnées. Le mode `strict_fidelity=True` refuse alors le document au lieu de présenter les coordonnées calculées en cache comme une fidélité stricte.

## Limites

Le moteur n'exécute pas le langage de formules Visio. Il ne reconstruit pas les maîtres, tous les styles, les rotations natives ni la sémantique complète des groupes. Ce correctif ne certifie donc pas l'interopérabilité avec Microsoft Visio Desktop. Les fixtures de régression sont des packages OPC/VSDX synthétiques.

## Qualification prévue

La qualification Windows doit exécuter les quatre régressions dédiées, toute la suite unittest à partir du checkout indépendant et à partir de l'archive extraite, ainsi que les builds portable/installer et les smoke tests. Les résultats ne seront publiés comme réussis qu'après observation du workflow sur le commit final.
