# OpenVisio V43.25 — état des captures Windows

Aucune capture réelle d'OpenVisio exécuté interactivement sous Windows n'est incluse dans ce candidat.

Les aperçus PNG produits par la CI proviennent du rendu des pages PDF d'architecture/qualification. Ils ne doivent pas être présentés comme des captures de l'application. Les smoke tests d'exécutable vérifient le démarrage et des opérations ciblées, pas la fidélité visuelle complète de l'éditeur.

La recette interactive Windows et le round-trip Microsoft Visio Desktop restent **NON EFFECTUÉS**.
