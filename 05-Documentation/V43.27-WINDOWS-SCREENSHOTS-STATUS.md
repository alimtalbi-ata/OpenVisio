# OpenVisio V43.27 — statut des preuves visuelles

Auteur : Abdelhalim Talbi.

- Captures réelles de l'interface Tk sous Windows : **NON DISPONIBLES pour ce candidat**.
- Recette interactive manuelle Windows : **NON EFFECTUÉE**.
- Aller-retour réel avec Microsoft Visio Desktop : **NON TESTÉ**.
- Les aperçus PNG générés par le workflow sont des rendus de pages PDF de qualification, pas des captures de l'application.
- Les fixtures OPC/VSDX des tests sont synthétiques. Elles ne certifient ni la fidélité des stencils Microsoft, ni les formules Visio, ni les styles/maîtres, ni les transformations complexes de groupes.

Ne pas convertir la réussite des tests unitaires, du packaging ou des smoke tests Windows en revendication de fidélité graphique Microsoft Visio.
