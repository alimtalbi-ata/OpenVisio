# OpenVisio V43.27 — ShapeSheet reference capitalization

**Author:** Abdelhalim Talbi  
**Scope:** bounded scalar formula evaluator and synthetic VSDX import regression.

## Change

The bounded evaluator resolves supported geometry cells, cached-cell references and \`ThePage!PageWidth\` / \`ThePage!PageHeight\` references without depending on capitalization. Function names were already normalized; this change extends normalization to references.

Case-fold collisions are not guessed: ambiguous geometry-target names reject the whole calculated set, ambiguous cached cells reject that dependency, and formula-bearing non-geometry references remain refused even when case differs. On failure the importer can retain cached \`V\` values and emit a fidelity warning; strict fidelity mode rejects unresolved geometry.

## Verification

The versioned formula unit test module now covers mixed capitalization, duplicate-case ambiguity, and refusal to substitute non-geometry formula caches. The VSDX geometry integration module exercises mixed-case page/cached-cell references through synthetic externalized OPC fixtures. The existing Windows workflow runs both test modules and rebuilds the package from its exact checked-out commit.

## Limits

This remains an allowlisted scalar subset, not a complete ShapeSheet implementation. The tests use synthetic VSDX fixtures. **Microsoft Visio Desktop round-trip: NOT TESTED.**

Reference: [Microsoft Learn — About Cell References](https://learn.microsoft.com/en-us/office/client-developer/visio/about-cell-references). This change normalizes capitalization only within the existing supported subset; it does not add external named-shape references or arbitrary Visio formula functions.
