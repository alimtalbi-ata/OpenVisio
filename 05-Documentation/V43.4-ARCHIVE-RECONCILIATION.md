## Historical V43.4 ZIP audit

The file OpenVisio-V43.4-Wide-Parallel-Lanes-Cumulative.zip was located in the project library and audited. Its SHA-256 is 3b473556df267c9c443574a3253badfa9664f8ed897c8ede9b83ef8495e00266. Its ZIP CRC is valid, it has 246 file entries, and the embedded SHA-256 list contains 245 entries with zero missing files or mismatches.

The package is nevertheless not a reproducible V43.4 source release:

- 07-Manifestes/manifest.json declares V42.8-partial-embedded-candidate, windows_qualified=false, microsoft_visio_qualified=false, and python_tests_run=188.
- That manifest references 07-Manifestes/SHA256SUMS.txt, which is absent. The actual hash list is 07-Manifestes/SHA256SUMS-V43.4.txt.
- The package contains 33 Python engine files only under 03-Sources/openvisio; python/openvisio and python/tests are absent.
- routing.py and parallel_geometry.py are absent from that archived engine.
- The archive test suite was actually rerun on this host: 201 tests, 2 skipped, 0 failures. The targeted wide-parallel-lanes test also passes. Neither result certifies Windows or Microsoft Visio Desktop fidelity.

## New V43.20 source/release gate

A standard-library validator now checks version metadata, source and test mirror parity, required core modules and dependencies, ZIP duplicate/path traversal, and complete SHA-256 coverage. Synthetic regression tests specifically reject the stale manifest/missing checksum reference and any incomplete or divergent engine mirror.

## Functional improvement: zoom-aware label level of detail

The Tk renderer suppresses only visual equipment text when the node is too small on screen to present a legible caption. Node geometry, stored labels, selection targets, connector routes and SVG/VSDX data are not mutated. At readable zoom, the full wrapped label appears. Synthetic tests cover low, boundary and normal zoom.

## Qualification boundaries

Windows build and installer smoke will be reported only from the candidate CI job. No real Microsoft Visio Desktop round-trip or manual end-user Windows session is certified by these synthetic/unit tests. The historic V43.4 equivalence remains unproven; this audit identifies the archived bytes and prevents them being silently relabelled as a current engine.
