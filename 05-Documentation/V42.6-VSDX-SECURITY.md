# V42.6 VSDX import security qualification

Author: Abdelhalim Talbi

The VSDX importer must reject embedded OpenVisio JSON without a SHA-256 manifest, reject a manifest with invalid schema or digest, reject duplicate ZIP entries and traversal paths, and reject decompression amplification above 200:1 for individual parts over 1 MB. The locally consolidated source candidate implements these checks and its 137 Python tests pass.

The GitHub branch is still missing the complete V42.6 source tree, including the VSDX module; this commit alone is not a CI qualification. No real Microsoft Visio fidelity test or Windows V42.6 build has been executed. No release should be published as qualified until the full source tree is pushed and Windows CI succeeds.
