# OpenVisio V43.26 — source parity and archive binding

Author: Abdelhalim Talbi. Date: 26 October 2026.

The cumulative release builder requires both engine mirrors (`03-Sources/openvisio`, `python/openvisio`) and both test mirrors (`04-Tests/tests`, `python/tests`). The V43.26 checkout verifier pins the Git blob identities of the changed renderer, SVG exporter, shape glyph module and new/updated tests, alongside the critical VSDX model/import/routing files and build inputs.

The Windows workflow fetches the selected commit into an independent checkout, verifies the full commit SHA and critical Git blob IDs, checks mirror path/content parity, runs the complete suite, builds and smoke-tests the portable executable and installer, and independently compares the resulting cumulative ZIP with the exact Git tree. The final ZIP SHA-256 sidecar and archive structure are verified in CI.

A manifest inside a ZIP is not sufficient by itself: final parity is accepted only when `verify_release_git_parity.py` compares packaged source/test bytes with the selected Git HEAD. No archive built before the final commit is considered the V43.26 candidate.

Synthetic VSDX and renderer tests are not Microsoft Visio Desktop qualification. Manual Windows acceptance and a real Visio round-trip remain explicitly separate requirements.
