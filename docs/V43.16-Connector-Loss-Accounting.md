# OpenVisio V43.16 — SAN connector loss accounting

Author: Abdelhalim Talbi. Development branch only; no production merge.

## Behavior
External public VSDX import preserves valid parallel SAN links, but Visio
connectors with only one resolvable end, a self-loop, or endpoints in
unsupported shape geometry cannot be represented by the current OpenVisio
edge model. Previous imports silently omitted them.

The importer now exposes `metadata.connector_links_skipped`,
`connector_links_skipped_by_reason`, and up to 12 sheet references in
`connector_links_skipped_examples`. It adds a GUI-visible
`fidelity_warnings` entry. A missing connector sheet is rejected even when
its endpoint points at an unsupported shape. No fabricated FC ports or edges.

## Reproduction / qualification
Six synthetic OPC fixture regressions failed (5 errors, 1 failure) before
the patch and passed after. Linux Python suite: 650 tests, 28 skipped,
0 failures; Linux Tk/Xvfb suite: 650 tests, 0 failures.
Windows CI status must be read from the V43.16 GitHub Actions run; never
assume compilation or Microsoft Visio Desktop fidelity from Linux tests.

## Limitations
No original historical V43.4 ZIP was supplied; parity with that version
remains unverified. Exact Visio route bend coordinates and native Microsoft
Visio Desktop fidelity are not certified. Incomplete Visio connectors are
reported but not recreated as dangling OpenVisio edges.
