# OpenVisio v41.14 — Session de mutation du rendu

Auteur : Abdelhalim Talbi

Le rendu SVG utilise désormais une session persistante de suivi des connexions par canevas. Les changements sont réconciliés avant invalidation ciblée du cache existant. Aucun deuxième cache de routes.

Limites : aucune compilation Windows ni capture réelle; benchmark comparatif SAN non effectué. Les guides Word/PDF historiques ne sont pas tous actualisés.
